## 🆘 Khi Gặp Khó Khăn

### 1. Concept không hiểu
**Thứ tự debug:**
1. Đọc lại docs (MDN)
2. Xem video tutorial
3. Google: "explain [concept] simply"
4. Hỏi ChatGPT/Claude với example cụ thể

### 2. Code không chạy
**Checklist:**
1. Check browser Console (F12) cho errors
2. Verify file paths (CSS linked correctly?)
3. Hard refresh (Cmd+Shift+R)
4. Copy error message → Google
5. Check [QUICK_REFERENCE.md](./QUICK_REFERENCE.md) for syntax

### 3. Stuck quá lâu (>2 giờ)
1. Take a break! 🧘
2. Code something simpler
3. Come back fresh
4. Đôi khi sleep on it works!

**Remember:**
- ✅ Bạn đã giỏi Backend - FE chỉ là skillset mới

## 💡 Pro Tips Từ Senior Dev

### 1. Hands-on Learning
**❌ Don't:** Chỉ xem tutorials  
**✅ Do:** Code along, break things, fix them

### 2. Build Projects Early
**❌ Don't:** Học hết rồi mới build  
**✅ Do:** Build while learning (learn by doing)

### 3. Google-fu is a Skill
**❌ Don't:** Nhớ hết mọi syntax  
**✅ Do:** Learn to search effectively

Example searches:
- "css center div flexbox"
- "javascript array filter multiple conditions"
- "react useState object update"

### 4. Read Others' Code
- Inspect websites (F12) → See how they did it
- Read GitHub repositories
- Frontend Mentor solutions

### 5. Use AI Wisely
**✅ Good:**
- "Explain this concept in simple terms"
- "Debug this error: [paste error]"
- "Best practice for [scenario]"

**❌ Bad:**
- "Write entire app for me" (you won't learn!)

### 6. Backend Advantage
Bạn có **competitive edge**:
- Hiểu APIs, async, data structures
- Can build full-stack apps
- **Leverage this!** → Build projects connecting React to Go backend
